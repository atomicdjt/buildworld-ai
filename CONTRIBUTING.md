# Contributing

BuildWorld AI is primarily a personal portfolio project. External contributions are not expected, but focused reports and improvements are welcome.

## Useful Contributions

- Reproducible bug reports
- Broken-link or documentation corrections
- Accessibility observations
- Test coverage for deterministic simulation logic
- Improvements that preserve the stated educational and exploratory scope

## Before Opening a Pull Request

1. Keep the change narrow and describe its user-facing impact.
2. Do not include secrets, private data, or real-world sensitive infrastructure information.
3. Preserve the responsible-use boundary described in the README.
4. Run the relevant checks:

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

By contributing, you agree that your contribution may be incorporated into the project under the repository's [Portfolio License](./LICENSE.md).
