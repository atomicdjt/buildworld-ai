# Security Policy

## Supported Version

Security reports are considered for the current default branch.

## Reporting a Vulnerability

Please do not disclose a potential vulnerability in a public issue. Use the contact method listed on the repository owner's GitHub profile and include:

- A concise description of the issue
- Steps to reproduce it
- A minimal proof of concept, if safe to provide
- The potential impact

Please use synthetic data only. BuildWorld AI is an educational, browser-based application and should not be used with sensitive operational data.
